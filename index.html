Solusi Cepat Error HTTP 401 (Permission Denied):

  1. Buka Firebase Console → Realtime Database → Rules pada proyek fleet-transaction-management.
  2. Pastikan Authentication → Sign-in method → Anonymous aktif. Lalu ganti isi Rules dengan konfigurasi di bawah ini dan klik Publish. Rules ini hanya mengizinkan pengguna yang sudah terautentikasi secara anonim:
{
  "rules": {
    "simkendis": {
      ".read": "auth != null",
      ".write": "auth != null"
    }
  }
}

Catatan keamanan: Jangan gunakan ".read": true atau ".write": true untuk database ini karena siapa pun yang mengetahui URL database dapat membaca atau mengubah data. Setelah Rules dipublikasikan, tekan Tes & Paksa Simpan Sekarang. Jika masih gagal, periksa Detail Error Teknis; error API key atau Anonymous Authentication tidak bisa diperbaiki hanya dengan mengubah Rules. Data yang belum tersinkron tetap tersimpan di browser ini.
